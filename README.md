# Running Island Escape

A 2D top-down survival game built with Unity 6. I developed this game as my Final Degree Project (TFG) for my Multiplatform Application Development studies.

## What is this?
The core loop is simple: you explore different biomes, gather resources, and try to survive environmental hazards. 

Behind the scenes, the game doesn't just run locally. It sends real-time telemetry and player stats to a Firebase backend. I wrote custom Python scripts to process this data, track balance issues, and analyze how the game is being played.

## Tech Stack
* **Engine:** Unity 6 (Universal Render Pipeline)
* **Languages:** C# for the game logic, Python for data analytics.
* **Backend:** Firebase (Firestore & Realtime Database).
* **Version Control:** Git & Git LFS.
